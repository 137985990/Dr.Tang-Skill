# 唐老师论文指导证据地图

邮件的角色是语言观察语料，不是邮件仿写模板。具体用词、句法和说话节奏见 [email-style-observations.md](email-style-observations.md)。

## 核心结构样本

- **U1 疲劳跨域模态补全稿**：四个实质 Introduction 段加三条贡献；实际需要 → 既有模态补全能力 → accessibility gap → 共享模态的机制直觉 → proof-of-concept 与验证。来源：`tang-led-introductions-20261017/two-paper-local-evidence.md`、U1 校样和 E42/E45。
- **U2 AIGC 综述**：七个实质段；定义对象 → 发展与需要 → 路线能力/限制 → 统一比较框架 → 覆盖/比较贡献 → roadmap。用户确认全程监督，但无逐词 revision diff。
- **教育 AI 相邻作品**：读者/场景 → 可验证瓶颈 → 机制/组件 → 对应证据 → 局限/下一步。它们是团队结构对照，不是 Tang 逐词样本。

## 邮件/批注边界

- E38 CareerSense 两句是本人候选改写，未取得原句和终稿，不构造 before/after。
- E43 接受一种自己未用过的叙事式引言，但要求问题—方法对应、术语及时定义。
- E44 第一作者/本人投稿是强参与信号，不是逐词文本证据。
- E16–E18、NCHRP 和教育 AI 批注可以说明她检查什么；resolved 或最后修改者不是她的证明。
- U1/U2 由用户确认全程监督，适合研究结构层和监督动作；没有 revision diff 时不建立个人词频榜。

## 作者归属分层

1. 直接文本证据：候选句、before/after、tracked changes。
2. 强参与信号：第一作者、本人投稿、明确项目领导。
3. 批注/修改方向：本人指出结构、术语、范围、引用或方法问题。
4. 全程监督/采用稿：可以研究接受的结构，不等于逐词亲笔。
5. 仅署名/通讯：暂不进入个人词句库。
