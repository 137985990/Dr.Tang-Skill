# 论文指导核心规则

## 1. 先做事实盘点

写作前列出：文章类型、读者、真实任务、已知事实、未定事实、最接近的工作、可支持的 claim、尚未取得的证据。实验未完成时写目标和待检验关系，不写结果型贡献。范文中的数据、模型、显著性和新颖性不能填入新稿。

## 2. 研究问题与范围

把研究问题写成后文能够回答的关系，而不是把方法名改成疑问句。先区分“是否存在/是否有效”“如何产生”“哪个组件起作用”“在什么条件下成立”；再核对计划中的活动、数据和评价是否真的能回答它。`How` 如果混入了影响、机制和组件三个问题，要拆开或缩小范围。研究问题、目标、方法和评价必须保持同一比较基准；新增问题若没有相应数据或活动，就不能作为贡献写入。

## 2. 原创研究/方法论文

按实际论证负担合并或拆开以下功能：

1. **任务与实际需要**：研究对象服务什么决策/场景？哪一现实条件使它不能可靠发挥作用？必要性在引言前部形成，不要求第一段最后一句固定收束。
2. **已有能力**：前人解决了什么，靠什么信息、监督、传感器、假设或机制？先承认有效范围，再说明限制。
3. **具体 gap**：在本文目标条件下仍缺什么？为什么最近工作不能直接覆盖？应用对象不同本身不足以证明新颖性。
4. **本文设计的理由**：从前述限制推出设计直觉、关系和必要假设，再介绍框架/组件；不要从 gap 直接跳到模型名。
5. **范围与验证**：本文究竟验证可行性、整合框架、算法改进还是其他主张？评价指标必须对应主张。
6. **贡献**：按问题定义、机制、证据或分析写；不要只改成平行语法而没有可兑现内容。

续作先交代前作做什么，再说前作留下的改进空间，最后引出本文。不要假设读者看过前作，也不要复制前作整套背景。

## 3. 综述论文

综述的 gap 是已有综合、范围、分类或比较视角还缺什么，不是声称领域没有方法。先定义对象和需要，再解释路线如何工作、能力如何变化、哪些限制推动下一阶段；随后给出共同比较维度、与最近综述的具体差异、贯穿例子/表格的用途和必要的 roadmap。分类数、贡献点数和段数服从论证，不为模仿范文硬凑。

## 4. Related Work

先说一类工作共同解决什么，再用代表论文说明真正差异。每类用一两句话交代与本文的 overlap、前提和边界。可以比较局限，但要新增文献分析，不重复 Introduction 的全部动机。具体实现选择的理由通常放在 Methodology/Experiments；Related Work 可以解释文献机制、条件和为什么不能直接覆盖本文。

## 5. Method、Experiments、Contribution

方法段先给原则：为什么这样设计、解决哪个 gap、依赖哪些假设。然后写输入、输出、执行顺序、数据采样、预处理、归一化、窗口、划分、阈值和停止条件；凡是做过的关键决定都要写出来。不能假设读者知道数据集内容。结果与预期冲突时，解释必须真正支持结论。

实验设计检查：

- 评价是否能回答研究问题；
- baseline 是否对应最近工作和本文条件；
- 数据、split、subject/window level、噪声和缺失设置是否明确；
- 结果强度是否超过证据；
- contribution list 是否在后文兑现。

## 6. 句法与用词

先确定关系，再选词。稳定复用技术对象名词，避免为了“高级”随意替换术语；generation、translation、augmentation、imputation、missing modality 等操作含义不同就保持区别。让步、因果、条件和目的必须真实：`To address this issue`、`Based on these observations`、`Nonetheless ... provided that`、`While we share ...` 都是功能选项，不是口头禅。where/when/if/because/since/given/so that 用来把 claim 放回条件。

句子要短到能跟上，但不能碎成标签；一个句子装了多个因果或转折就拆开。明确主语和动作，术语在读者需要用它理解判断之前定义。规范英语优先，不模仿邮件中的省略、拼写或语法错误。

## 7. 写完后的闭环检查

- 每段中心判断能否复述？支持材料是否都服务它？
- 上段给出的能力/限制是否真正引出下段？有没有只重复再加例子？
- 每个 gap 是否有原因、后果和本文解决范围？
- 最近工作是否公平说明，并写出 why-not-direct-apply 的机制或条件？
- 术语、符号、缩写是否在需要前定义且全文一致？
- claim 是否有 citation 或足够窄？`all/none/first/novel/striking` 是否超出证据？
- 方法、实验、贡献和结论是否互相对应？
