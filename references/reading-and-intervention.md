# 具体干预：她读到什么，为什么停下来，怎样继续写

以下动作来自两组会议转写和可归属评论。带引号的短语见末尾的来源编号；“反馈示范”和英文改稿均是本 skill 构造的练习，不是她的原话。按当前草稿选择相关动作，不逐项给文章套一遍。

## 1. 先把作者的意思说回去，而不是给形容词找同义词

**实际干预。** 疲劳稿把数据 richer、数据少、质量低接在一起。她问 `what do you mean by richer`，随后复述：这些生理信号能表征疲劳，但在真实场景难以采集。她再确认这是不是作者想表达的意思。[T1a]

**怎样做。** 先指出比较轴：richer 是通道多、样本多，还是信息更有用？把作者原本的判断说成一句清楚的话，再组织原有材料。若意图已能确认，不要让作者回答一串本可自行解决的问题。

**反馈示范。** “你想说的是这些信号有用，但现场不容易取得。现在的 rich 却让人先想到数据很多，后面又说 scarce。先把‘有用’和‘可获得’分开。”

这与单独把 rich 换成 informative 不同：后者仍可能保留错误的比较。词的具体性以当前论证需要为准，不要求每个形容词都有公式定义。

## 2. 把混在一起的原因拆开，再选本文真正处理的那一条

**实际干预。** 她追问昂贵的 collection/annotation 为什么会推出质量低；数量不足与噪声引起的质量问题没有被解释成同一因果。[T1b]

**怎样做。** 分别还原“条件 → 直接后果”。再把每个后果接到本文实际能做的事。若作者确有预算导致只能使用低精度设备的证据，成本与质量可以建立间接联系，写出中间条件即可。

**练习原句。** “Collecting and annotating signals is expensive, resulting in low-quality data. Our cross-domain framework solves these problems.”

**反馈示范。** “贵可以解释为什么收得少，为什么质量差还缺一步。即使这两点都成立，跨域框架也不自动降低标注成本。先说明你究竟要让哪一种缺失信息可用。”

**条件已知时的修稿示范。** 假设本文只研究源域 EEG/ECG、目标域仅有 ECG，以及用共享通道估计未采集的 EEG：

> The source data contain EEG and ECG, whereas the target setting considered here records only ECG. We investigate whether relationships learned from the source data can support EEG estimation in this setting. The study uses existing model components to examine the feasibility of this framework.

这里补的是具体设置与方法为何出现。不能因这个示例就把所有疲劳稿改成同一设置，也不能为了补动机另加未提供的生理学判断。

## 3. 从一个词检查读者会等待哪一种后文

**实际干预。** 她追问后文是否做 annotation；指出 missing segment、incomplete modality、wild 会让读者朝不同问题理解。相关困难可以真实存在，却未必属于当前论文要处理的事。[T1c]

**怎样做。** 写清“这里的 X 会让读者期待 Y；本文实际做的是 Z”。之后删去抢走主线的引线，或把 X 限定成 Z；论文确实研究 Y 时则保留，并补上它在方法与评价中的落点。

**反馈示范。** 假设作者已确认目标场景从未采集该通道：“missing segment 是通道中一部分时间点没了，你这里是目标场景整个通道都没采。读者会把两种任务混起来。直接写清 absent throughout the target data，而不是换几个 missing 的同义词。”

她对一份叙事式引言的反馈也体现这个动作：接受不同文风，同时追问 RAG 是否真的接住首段问题，以及 orchestration 在需要其含义前是否解释清楚。[F3，反馈内容为转述] 本包未保留这些问题的英文原句或完整学生稿，不能补造首段的具体情节。

## 4. 在读者需要时补前提，解释量由这个需要决定

**实际干预。** 作者突然说 previous work 和 temporal encoding，她追问前作是什么；同时明确“把握多和少 / 是看场景而来的”。另一份稿中，她要求 Direct、CoT、ToT 先被定义再用于比较。[T1d、D2]

**怎样做。** 对当前句倒问：读者要接受这个判断，必须已经知道什么？用最少但够用的功能说明交代旧法、操作或术语。仅给一个引用或把缩写展开，未必足够；引言也不必提前装进所有实现细节。

**反馈示范。** “你现在说要改进前作，但我还不知道前作处理什么。先说它怎样使用已有通道、留下了什么限制，再引出这次改动。编码细节等读者知道为何需要它以后再展开。”

## 5. 把最接近的方法放在同一层次比较，让差别经得起追问

**实际干预。** 作者以情感分析与疲劳应用不同来解释差异。她用“已有一种信息 → 从另一来源取得缺的信息 → 联合决策”重述两者，追问到底哪里不同；随后强调她未读原文，作者应根据读过的材料反驳。她还要求每类用一两句话总结与本文的 overlap，而不是照示例硬凑分类。[T1e]

**怎样做。** 先用同一组问题重述两法：输入是什么，缺什么，怎样利用关系，输出什么。保留真实共同点，再写会影响能力或贡献的条件/操作差异。应用名称不同可以重要，但要说明它改变了什么，而非直接推出旧法不能用。

**反馈示范。** 假设本稿已明确沿用对方的 attention 模块，且缺失通道适用性尚未核对：“两者都学通道关系，你还沿用了它的 attention。这一点先承认。目标域少一个通道可能是关键差别，但要核对：旧法真的要求各域通道一致，还是论文只做了这样的实验？现在只能写设置不同，不能先写方法不能应用。”

教师式追问不是技术结论。材料不足时交付可成立的比较，同时标明需要查的是方法前提、推理输入还是实验覆盖；不要凭反问判旧法无效，也不要求作者必须另造一个算法才有贡献。

## 6. 示例要展示方法怎样做，而不只是摆出题目

**实际干预。** 在 prompting 稿的题目与约束表旁，她评论 `This sounded just a problem definition`，问是否需要 Direct 的示例；另一条要求用 common example 和各法伪代码来显示差异。[D2、F2]

**怎样做。** 查示例究竟让读者看到了题目，还是看到了该方法实际收到什么、执行什么、得到什么。若“直接把问题交给模型”本身就是 Direct，补清这一对应就可能足够，无需为了增加步骤而改变方法。

多方法比较时，同一问题能帮助读者隔离操作差异。是否给伪代码取决于读者是否仍无法复现或辨别这些操作，不是每篇综述、每个模块的强制格式。

## 7. 继续问到已知、假设与观察的边界清楚为止

**实际干预。** 提案把模拟条件与行为效果写在一起。她先说明自己如何理解，再问究竟模拟什么、为何需要、如何得到行为；随后追问：若已经知道怎样模拟行为，是否也已经预设了本来要研究的处理效果？[D3]

**怎样做。** 分清作者操纵的条件、模型假设的机制、参与者实际产生的反应，以及待发现的结果。用这四者修正文句和评价范围，而不只泛泛要求“增加实验”。

**反馈示范。** “这里看起来像模拟器已经知道某处理会怎样改变行为。如果这是你要测的效果，就不能先把它写进模拟规则。请说明系统只模拟视觉条件，还是也预测行为；两种情况能支持的结论不同。”

同一思路可用于实验或 reviewer response：对方质疑的到底是哪一步？给出的结果、修改或解释是否回答它？答复声称修改过的内容要在正文落地。已有团队回复稿的感谢方式不一致，按当前期刊或项目模板处理，不用单次语气偏好作硬性规范。

## 邻段之间也这样读

如果第二段只是重说第一段再加例子，读者没有得到下一步。她在另一组转写中示范：首段可以先交代任务与已有能力，下一段再解释这些能力成立的条件及实际限制。她也把 AI 建议的部分“缺项”推迟到后段，因为当前段还不需要那些上下文。[T2]

因此，处理段间问题时指出实际缺的条件、原因或边界。合并重复；延后现在不需要的细节。先修论证，再决定是否需要 However、Therefore 等显式连接。
